# 🦷 Dental Clinic Management System

A production-ready, modern, and secure Dental Clinic Management System built with the MERN stack (MongoDB, Express.js, React, Node.js). Designed to provide a premium, calm, and professional experience for clinic administrators, dentists, receptionists, and accountants.

## 🚀 Features
- **Role-Based Access Control (RBAC)**: Admin, Dentist, Receptionist, Accountant.
- **Patient Management**: Comprehensive profiles, medical/dental history, and treatment records.
- **Appointment Scheduling**: Calendar views, status tracking, and dentist assignment.
- **Billing & Financials**: Invoices, partial payments, expense tracking, and revenue analytics.
- **Security**: Helmet, CORS, Rate Limiting, HTTP-only cookies, JWT, and centralized error handling.
- **Modern UI**: Clean, accessible, and responsive design using plain CSS with a professional medical color palette.

## 🛠️ Technology Stack
- **Frontend**: React, Vite, React Router, React Hook Form, Zod, TanStack Query, Lucide React, Plain CSS.
- **Backend**: Node.js, Express.js, MongoDB, Mongoose, Winston (Logging), Express Validator.
- **Security**: Helmet, CORS, Rate Limiting, bcryptjs, jsonwebtoken.
